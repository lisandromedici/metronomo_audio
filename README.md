# Metronomo audio

Pagina local para cargar un archivo de audio, elegir BPM y reproducirlo despues de una cuenta de metronomo.

## Uso

1. Abrir `index.html` en el navegador.
2. Elegir un archivo de audio, por ejemplo MP3, WAV, M4A u OGG.
3. Ajustar BPM, cantidad de tiempos de cuenta y volumen del click.
4. Presionar **Iniciar**.

No sube el audio a internet: el archivo se lee localmente en el navegador.
